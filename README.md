# DprE1 ML Bioactivity Prediction

Machine learning benchmarking (Random Forest, SVR, XGBoost) with SHAP 
interpretability for predicting bioactivity against DprE1 
(Decaprenylphosphoryl-beta-D-ribose oxidase), a validated drug target 
in *Mycobacterium tuberculosis* (CHEMBL3804751).

## Status
🔵 In progress — Section 1 of 13 (Data Acquisition) complete.
156 raw IC50 bioactivity rows pulled from ChEMBL.

## Data
Bioactivity data (IC50) sourced from ChEMBL.

## Tools
Google Colab, RDKit, scikit-learn, XGBoost, SHAP, pandas.
